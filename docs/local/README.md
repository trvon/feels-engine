# Local notes

Files in this directory except this one and `*.example.*` are ignored by git.
Keep device serials, display ids and anything about your own phones here.

Copy `devices.example.sh` to `devices.sh`, fill it in, and source it before
the commands in `../build.md`:

```bash
source docs/local/devices.sh
```

The Play Store listing (texts, icon, feature graphic, screenshots and the
console walkthrough) lives in `store/` here, not in the repo.
